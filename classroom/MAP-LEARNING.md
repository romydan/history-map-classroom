# 六册逐课地图学习清单

地图按学习任务组织。行进、交通路网、组织关系、战线、区域与分布使用不同表达；没有路线的史事不按事件顺序硬连。

路线是关键地区与方向的教学示意。现代轮廓定位、历史教学快照和区域概略圈分别标注；不视为同一种国界。

课程标准用于确定识图、时空联系等学习能力，不据此宣称某地中考必考。来源与精度见站内“教材与地图来源”和数据文件。
