# 历史地图课堂

面向初中历史课堂与自主学习的教材地图。默认展示九上第14课《探寻新航路》，六册共133课、358个课程相关事件或主题节点。

## 本地运行

在仓库根目录执行：

```sh
python3 -m http.server 63418 --bind 127.0.0.1 --directory classroom
```

打开 `http://127.0.0.1:63418/`。无需安装前端依赖，也没有运行时服务端。

## 验证与发布

```sh
node classroom/scripts/validate.mjs
node classroom/scripts/build.mjs
```

构建只把显式允许的课堂文件复制到 `classroom-dist/`。GitHub Pages 必须上传该目录，不能上传整个上游仓库。教材文件、扫描图和CHGIS郡县层不属于发布内容。

## 使用

从六册目录选择单元和课程，然后选择“开始授课”或“开始学习”。本课时序与地图联动；展开事件背景、经过、影响；探究区提供逐步提示和参考思路。左右方向键切换本课事件，`/` 聚焦搜索，`Esc` 收起浮层。地图支持拖动和缩放按钮，距离尺随缩放与视图中心纬度更新。切换授课与自学保留课程、事件和地图视野。

课程链接包含教材、课次、事件、模式；分享按钮另保存当前地图视野。学生标记与文字草稿仅保存在本机浏览器。“投屏”进入全屏大字授课视图，浏览器不支持全屏时仍可使用大字视图。

来源核对范围和数据精度见 [ATTRIBUTION.md](ATTRIBUTION.md)。课程数据不附带教材原文或图像。

## 地图学习层

见 [六册逐课地图清单](MAP-LEARNING.md)。data/map-learning.json` 把每课读图任务、路线、区域、地点、来源及阶段引用单独保存；路线不能直接由事件点顺次连成。非单点事件可用空坐标，以相关区域或多处活动地点呈现。

点击图例中的“全课总览”可比较完整网络；沿时间轴授课时突出当前阶段，浅色线表示后续参照。展开“关键地点、路线与区域”，可用“定位此段”观察局部，并查看读图问题及思路。
